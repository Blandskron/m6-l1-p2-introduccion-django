🛣️ El Enrutador y Soporte de Bases de Datos

Dos pilares fundamentales de Django son su enrutador limpio y declarativo (controlado en `urls.py`) y su sistema de abstracción de base de datos a través de un ORM (Object-Relational Mapping). Ambos componentes permiten que una aplicación Django escale, sea modular y mantenga el código libre de repeticiones (DRY).

🗄️ Soporte Integrado de Bases de Datos

Django provee soporte nativo y abstracción total para bases de datos relacionales a través de su **ORM**. Esto significa que escribes tus modelos en Python y Django genera las sentencias SQL correspondientes por ti.

Soporte Multimotor Nivel Corporativo:

  • SQLite: Motor de base de datos integrado en archivos. Configurado por defecto para desarrollo ágil y pruebas locales.
  • PostgreSQL, MySQL, MariaDB, Oracle: Motores de nivel empresarial. Para conectarlos, solo debes instalar el driver Python correspondiente y actualizar el diccionario DATABASES en settings.py.

El ORM de Django promueve el principio DRY ya que evita escribir consultas SQL crudas en tus vistas, permitiendo que tu base de datos sea intercambiable sin romper la lógica.
